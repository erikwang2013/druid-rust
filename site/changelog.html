v1.4.0 2026-10-19AddedFixed

功能版：宠物表情形态正式进入 druid-console，同时修复代理层语句钩子、鉴权下的 favicon 加载与 stable 工具链的 clippy 失败。测试总数 428 到 431。

新增

  • 12 个表情 SVG 移入 druid-console/assets/pet-expressions/ 并随 crate 发布，新增 GET /druid/pet/<name>.svg 路由。
  • 监控页头按状态自动切换表情：SQL 错误对应愤怒，慢 SQL 对应沮丧，池用满对应敲打，尚无执行对应卖萌，正常对应微笑。
  • 防漂移测试保证 docs 与 crate 内副本字节一致，新增 GitHub Social Preview 图。

修复

  • 代理层补齐 statement_created、statement_error、statement_closed，执行失败或被拦截时不再漏记错误。
  • 鉴权开启后，/druid/mascot.svg 与 /druid/pet/<name>.svg 不再要求 Bearer token，favicon 不会 401。
  • WallProvider::new(..., 0) 现在真正禁用缓存，与 PSCache 的 0=禁用语义一致。
  • 适配 Rust 1.99 stable 的 clippy，迁移到 Atomic::try_update。
v1.3.1 2026-10-01SecurityFixed

1.3.0 发布当日的补丁。对抗验证又挖出 5 组配置 Debug 明文口令泄漏与 1 个打包缺陷。

安全：DruidConfig 的 Debug 输出

  • userinfo 旁边的参数值：改为从右往左取第一个不在参数值里的 @，豁免只作用于分隔符本身。
  • scheme 段：按 SAFE_SCHEME_LABELS 白名单逐段比对，未知标签整段打码。
  • 键名标签：值是否打码仍用子串判断，键名能否回显改为精确白名单。
  • 收敛为一条原则：每一段都要判定，判定范围等于作用范围。

打包与发布

  • 吉祥物资产移入 crate 目录，修复 cargo package 缺文件导致的编译失败，并加防漂移测试。
  • druid-wall 与 druid-console 首次发布到 crates.io。
  • 10 个 crate 补 readme 字段，crates.io 页面显示项目 README。
v1.3.0 2026-10-01BreakingSecurity

深度审查与三轮对抗验证后的集中修复。核心结论：1.2.0 的 SQL 防火墙与统计在连接池路径上从不执行，因为 Filter 无处挂载，PoolGuard 只暴露裸连接。

破坏性变更

  • 防火墙默认 fail-closed：解析失败或语句类型无法识别的 SQL 一律拒绝。逃生开关为 deny_unparsable = false。
  • DruidConfig::filters 非空时 init() 返回错误，请改用 DruidDataSource::with_filters(...)。
  • DruidError 加 #[non_exhaustive]，下游穷尽 match 需要补 _ =>。
  • max_lifetime_ms 改为按物理连接创建时刻判定，原先按最近使用时刻，热点连接下实际从未生效。
  • 非法配置如 initial_size > max_active 现在由 DruidConfig::validate() 在 init 时报错。
  • druid-ha 删除无消费者的 NodeStatus::Testing；substitute_params 标记 deprecated，请改用 substitute_params_mysql。

新增

  • 构造期注入：with_filters() 与 with_chain()，链在包装为 Arc 前配置完成，无注册竞态。
  • PoolGuard::execute() 与 query()：唯一会让 SQL 流经 Filter 链的入口，connection() 保留为绕过 Filter 的逃生通道。
  • 补齐 5 个定义了却从不 dispatch 的生命周期钩子，新增 impl Filter for Arc<T>。
  • 控制台 token 鉴权、常量时间比较、Cache-Control: no-store、SQL 接口分页。
  • 防火墙 deny_unparsable、事务控制语句安全通道、更多 DenyOperation 归类。
  • 解析器支持 LIMIT offset, count、@var 与 EXPLAIN。
  • 高可用新增失败/成功阈值、探测超时与可停止的健康检查循环。

安全修复

  • 防火墙解析失败只告警就放行、quick_check 的 deny 结果被丢弃，8 条绕过全部封堵。
  • 函数黑名单不递归参数，COALESCE(SLEEP(5),0) 可绕过，现递归遍历。
  • CREATE TABLE ... DEFAULT (RAND()) 绕过，已在真机复现并封堵。
  • deny_keywords 两次被引号致盲，改为用词法器 token 流重建匹配文本。
  • substitute_params 反斜杠注入，新增 MySQL 安全版本。
  • 配置 Debug 明文口令泄漏，改为逐段白名单脱敏。
  • 控制台无鉴权暴露 SQL 原文，增加 token 与回环地址建议。
  • crypto 未启用 zeroize feature，轮密钥与临时密钥未清零，现已启用。

正确性与并发修复

  • 连接池取消安全：提前构造 pending guard，取消时不再泄漏物理连接。
  • 修复 close 返回后仍创建并交付连接、归还校验窗口计数失真、close 不唤醒排队者。
  • KeepAlive 不再关掉正在使用的连接，校验期间与借用路径共用同一套状态语义。
  • 修复 permit 先于连接归位释放导致物理连接数超过 max_active。
  • DruidDataSource 增加 Drop，不再泄漏后台任务与空闲连接。
  • 高可用修复节点卡死、巡检无单点超时、单次失败即判死、健康检查无法停止。
  • 统计修复 SQL 表无上限、active/idle 单向漂移、持锁打印未截断 SQL。
  • 解析器修复 NOT 优先级错误、递归无深度上限、达到迭代上限后静默截断、把 -- 一律当注释。
  • 格式化修复字符串不转义、CREATE TABLE 丢约束、二元运算缺括号、JOIN 输出字面量。
