安装文档

把连接池装进你的项目

Druid-Rust 是一个 Rust workspace，核心 crate 可以单独引入，也可以按需组合防火墙、统计与控制台。

目录

当前版本：1.4.0 · 431 项测试通过 · Apache-2.0。以下依赖版本统一使用 1.4。

环境要求

  • Rust stable 工具链，edition 2021。
  • tokio 异步运行时，示例使用 features = ["full"]。
  • 一个可用的数据库，以及实现 Driver 与 Connection trait 的驱动适配层。项目不内置数据库驱动。

如果你只需要 SQL 解析器或防火墙，可以单独引入对应 crate，不必使用连接池。

添加依赖

在 Cargo.toml 中加入需要的 crate。最小组合是 druid-core 加 druid-pool。

Cargo.toml 
# 版本统一为 1.4
[dependencies]
druid-core = "1.4"
druid-pool = "1.4"
druid-wall = "1.4"
druid-stat = "1.4"
tokio = { version = "1", features = ["full"] }

也可以直接用 cargo add：

终端 
cargo add druid-core druid-pool druid-wall druid-stat
cargo add tokio --features full

最小示例

创建数据源、预热连接、借出一个 guard，再让它自动归还。示例里的 your_driver 需要替换成你的驱动实现。

src/main.rs 
use druid_core::DruidConfig;
use druid_pool::DruidDataSource;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut config = DruidConfig::new(
        "mysql://localhost:3306/mydb",
        "root",
        "password",
    );
    config.initial_size = 5;
    config.max_active = 20;
    config.min_idle = 3;

    // your_driver 需要实现 druid_pool::Driver
    let ds = DruidDataSource::new(your_driver, config);
    ds.init().await?;

    let guard = ds.get_connection().await?;
    // 通过 guard.execute() / guard.query() 执行 SQL，Filter 才会生效
    drop(guard); // 自动归还

    ds.close().await?;
    Ok(())
}
注意：guard.connection() 是绕过 Filter 的逃生通道。走它执行 SQL，防火墙与统计都不会生效。

从源码构建

需要参与开发或使用未发布改动时，可以直接构建整个 workspace。

终端 
git clone https://github.com/erikwang2013/druid-rust.git
cd druid-rust
cargo build --release
cargo test --workspace
cargo run --example basic

Release 构建启用了 LTO、codegen-units = 1 与 opt-level = 3。

验证安装

先做一次快速编译检查，再确认依赖树里出现了目标 crate。

终端 
cargo check
cargo tree -p druid-pool

运行测试时，完整 workspace 应显示 431 项通过。测试分布可在 README 的「开发与测试」章节查看。

常见问题

配置了 filters 字段，为什么 init 报错？

DruidConfig::filters 从未接线。请改用 DruidDataSource::with_filters(driver, config, filters)，在构造期注入 Filter 链。

合法 SQL 被防火墙拒绝？

防火墙默认 fail-closed，解析器尚未支持的语法会被拒绝，例如 UNION、SHOW、USE、SET、EXPLAIN FORMAT=TREE。确认风险后再显式设置 deny_unparsable = false。

控制台请求返回 401？

使用 start_server_with_token() 后，数据与页面端点需要 Authorization: Bearer <token>。静态宠物资源仍然公开，便于浏览器加载 favicon。

能直接使用 sqlx 或 tokio-postgres 吗？

本项目定义了自己的异步 Driver 与 Connection trait，不依赖 JDBC，也不内置 ORM。你需要写一层驱动适配，把数据库客户端接到这两个 trait 上。
